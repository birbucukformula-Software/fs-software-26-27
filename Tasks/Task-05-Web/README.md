# Görev 5: Web Birimi Sunumu

## 🔍 Araştırılacak Konu Başlıkları
* Web geliştirmenin temelleri: HTML, CSS ve JavaScript'in rolleri
* Frontend (Önyüz) ve Backend (Arkayüz) kavramları ile aralarındaki farklar
* API (Application Programming Interface) nedir, nasıl çalışır?
* React, Vue veya Angular gibi modern teknolojilere genel bakış
* Sensör ve telemetri verilerinin web arayüzünde canlı (real-time) gösterimi

## 📤 Teslim Formatı ve Yeri
* **Format:** PDF formatında hazırlanmış, web birimini anlatan bir sunum dosyası. (Örn: `Web-Birimi.pdf`)
* **Teslim Yeri:** Hazırladığınız dosyayı ana dizindeki `Submissions/Submission-05-Web-Ad-Soyad` klasörünün içine ekleyip Pull Request atmalısınız.
