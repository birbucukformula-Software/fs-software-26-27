# Görev 1: Sunum Nasıl Yapılır?

## 🔍 Araştırılacak Konu Başlıkları
* Etkili bir sunumun temel bileşenleri nelerdir?
* Slayt tasarımı ve görsel hiyerarşi (Az metin, çok görsel mantığı)
* Beden dili, ses tonu ve dinleyici ile göz teması
* Sunum heyecanını yenme ve zaman yönetimi
* Hikaye anlatıcılığı (Storytelling) ile teknik konuları basitleştirme

## 📤 Teslim Formatı ve Yeri
* **Format:** PDF formatında hazırlanmış bir sunum dosyası. (Örn: `Sunum.pdf`)
* **Teslim Yeri:** Hazırladığınız dosyayı ana dizindeki `Submissions/Submission-01-Sunum-Ad-Soyad` klasörünün içine (kendi ad-soyadınıza göre oluşturarak) ekleyip Pull Request atmalısınız.
