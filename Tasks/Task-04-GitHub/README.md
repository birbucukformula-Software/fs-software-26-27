# Görev 4: GitHub Nasıl Kullanılır?

## 🔍 Araştırılacak Konu Başlıkları
* Git ve GitHub arasındaki temel fark nedir?
* Temel Git komutları: `clone`, `add`, `commit`, `push`, `pull`
* Branch (Dal) yapısı neden kullanılır ve nasıl yönetilir?
* Fork, Pull Request (PR) ve Code Review kavramları
* Commit mesajı standartları (Anlaşılır ve açıklayıcı mesaj yazma)
* Merge Conflict (Çakışma) nedir ve nasıl çözülür?

## 📤 Teslim Formatı ve Yeri
* **Format:** Markdown (`.md`) veya PDF formatında hazırlanmış, GitHub kullanımını özetleyen bir sunum/rapor dosyası. (Örn: `GitHub.pdf`)
* **Teslim Yeri:** Hazırladığınız dosyayı ana dizindeki `Submissions/Submission-04-GitHub-Ad-Soyad` klasörünün içine ekleyip Pull Request atmalısınız.
