# Görev 7: Gömülü Birim Sunumu

## 🔍 Araştırılacak Konu Başlıkları
* Gömülü sistem (Embedded System) nedir? Kişisel bilgisayarlardan farkı nedir?
* Mikrodenetleyiciler (Microcontroller - MCU) ve Mikroişlemciler
* STM32 ailesine ve ARM mimarisine genel bakış
* C ve C++ dillerinin gömülü sistemlerdeki yeri (Neden hala vazgeçilmezler?)
* Haberleşme protokolleri temelleri (Özellikle otomotivde kullanılan CAN Bus)

## 📤 Teslim Formatı ve Yeri
* **Format:** PDF formatında hazırlanmış, gömülü sistemleri anlatan bir sunum dosyası. (Örn: `Gomulu-Birim.pdf`)
* **Teslim Yeri:** Hazırladığınız dosyayı ana dizindeki `Submissions/Submission-07-Gomulu-Ad-Soyad` klasörünün içine ekleyip Pull Request atmalısınız.
