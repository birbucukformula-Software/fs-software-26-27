# Görev 8: Otonom Birim Sunumu

## 🔍 Araştırılacak Konu Başlıkları
* Otonom sürüş nedir? Otonomi seviyeleri (Seviye 0 - Seviye 5) nelerdir?
* Çevreyi algılama: Sensörler (LiDAR, Kamera, Radar, Ultrasonik) ve çalışma prensipleri
* Bilgisayarlı Görme (Computer Vision) ve Makine Öğrenmesinin (Machine Learning) otonomideki rolü
* Path Planning (Yol Planlama) ve SLAM (Eşzamanlı Konumlandırma ve Haritalama) algoritmalarına giriş
* Otonom sistemlerde güvenlik, kararlılık ve tepki süresinin (Latency) kritik önemi

## 📤 Teslim Formatı ve Yeri
* **Format:** PDF formatında hazırlanmış, otonom araç teknolojilerini anlatan bir sunum dosyası. (Örn: `Otonom-Birim.pdf`)
* **Teslim Yeri:** Hazırladığınız dosyayı ana dizindeki `Submissions/Submission-08-Otonom-Ad-Soyad` klasörünün içine ekleyip Pull Request atmalısınız.
